"Firm Quill" is an original vertical TikTok ad for make.fun, built for the "Bring the humans with a TikTok ad" bounty. The ad invites people to build software with AI agents on make.fun and earn cash rewards, and it is ranked by its TikTok views — the top 20 entries by views share the $500 prize pool (USDC).

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `VIDEO.json` — which names the publicly posted TikTok video — from the repository root into the output directory, where the grader reads it.

> Note: `VIDEO.json` is not in this repository yet. It is added only after the ad video has been posted publicly on TikTok, so it can carry the video's real URL.
